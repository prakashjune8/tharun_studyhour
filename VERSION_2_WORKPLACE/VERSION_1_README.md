# 🛡️ ScholasticPulse - Version 1 (Safe Reset / Reboot Point)

> **Timeline Checkpoint**: This directory preserves the **clean, functional Version 1 baseline** of the application as it existed **right before the 1-on-1 design & beautification discussion started**.
> 
> It serves as an inviolable, permanent **Safe Reboot Point** that you can launch, inspect, or restore anytime if anything goes wrong.

## 🚀 How to Use Version 1:

1. **To Launch Version 1 directly**:
   * Double-click `LAUNCH_V1_PYTHON.bat` (runs with Python)
   * Or run `LAUNCH_V1_APP.bat` (runs standalone executable)

2. **To Compile a Standalone Version 1 Executable**:
   * Double-click `BUILD_V1_EXE.bat` -> Builds `dist/ScholasticPulse_V1.exe`

3. **To Restore Version 1 Back into Root Project Folder**:
   * Double-click `RESTORE_THIS_V1_TO_ROOT.bat` (inside this folder)
   * Or double-click `RESTORE_TO_VERSION_1.bat` in `d:\THARUN PROJECT`
