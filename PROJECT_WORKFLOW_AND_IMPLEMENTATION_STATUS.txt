1. PROJECT OVERVIEW & ARCHITECTURAL FOUNDATION
--------------------------------------------------------------------------------
ScholasticPulse V2 is a dual-platform pedagogical productivity system designed
specifically for an 8th-grade CBSE student. It pairs anime-inspired motivation
(Naruto Shinobi theme) with rigorous academic routine design, cognitive variance
auditing, and automated school timetable balancing.

Dual Platforms:
1. Web Application (index.html):
   - Fully client-side SPA written in vanilla HTML5, CSS3, Tailwind CSS (CDN),
     and high-performance vanilla JavaScript.
   - Persistent via localStorage.
   - Complete 9-section UI redesign approved and functional.

2. Desktop Application (study_balancer.py):
   - Standalone Python 3.10+ Tkinter application with custom Canvas vector
     drawing, Windows Win32 API integration, and native audio.
   - Self-contained executable built via PyInstaller (ScholasticPulse_V2.spec).
   - Local JSON persistence (study_routine_data.json, tharun_diary_format.json,
     time_extension_audit.json, student_error_bank.json).

Pedagogical Core Rules:
- Inviolable 10:00 PM Bedtime Protection: Overruns dynamically compress breaks
  or non-critical slabs, never pushing sleep past 10:00 PM.
- Daily Cognitive Muscle: Mathematics problem-solving is scheduled every single day.
- Cognitive Variety / Interleaving: Homework tasks are split into maximum 1 or 2
  focused efficiency slabs with 3-4 minute micro-breaks.
- After-School Transition: 5:40 PM - 6:30 PM is a protected "Unplugged Chill Zone"
  with zero television before studying.
